# autumn-job-assistant
秋招助手——帮助应届生进行秋招求职，快速填写
## 🚀 使用方式

### 🧩 本项目基于 Tampermonkey（油猴）脚本运行

**秋招助手主要通过浏览器 Tampermonkey（油猴）扩展运行，无需安装独立客户端。**

使用前请先安装 Tampermonkey：

1. 安装浏览器扩展 **Tampermonkey（油猴）**。
2. 打开本项目中的：
   `tampermonkey/campus_autofill.user.js`
3. 将脚本代码复制到 Tampermonkey 的新脚本中。
4. 保存脚本并启用。
5. 打开需要填写的校园招聘网申页面。
6. 页面加载完成后，右下角会出现 **「⚡ 秋招助手」悬浮球**。
7. 点击悬浮球即可打开助手，并使用：
   - ⚡ 一键填简历
   - 📋 简历小助手
   - 🎯 当前字段识别
   - 📑 个人资料快速填充
   - 📊 表单填写进度统计

### 📌 支持的使用场景

秋招助手主要用于辅助填写校园招聘网申表单，例如：

- 企业校园招聘官网
- 第三方招聘系统
- 北森等招聘系统
- Moka 等招聘系统
- 大易等招聘系统
- 企业自研招聘页面
- 高校就业招聘网站
- 本地 HTML 测试表单

> 实际兼容情况取决于目标网站的表单结构及前端实现。

### 🔒 数据说明

个人简历资料默认保存在本地，示例项目使用虚拟的「张三」测试资料。

**请不要将真实身份证号、手机号、家庭成员信息等敏感个人资料直接提交到公开 GitHub 仓库。**
