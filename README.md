# ⚡ 秋招助手

### Campus AutoFill Assistant · Tampermonkey

一个面向应届毕业生的 **AI / 自动化网申辅助工具**，通过 Tampermonkey（油猴）脚本运行，帮助用户快速完成招聘网站中的简历信息填写。

> 🎯 **安装油猴 → 安装脚本 → 打开网申页面 开始使用**

---

## ✨ Features

- ⚡ 一键填充简历信息
- 📋 个人简历资料管理
- 🔍 自动识别页面表单字段
- 🎯 当前字段快速填充
- 📊 网申填写进度统计
- 🧩 支持不同招聘网站的表单结构
- 💾 本地保存个人资料
- 🛠️ 提供本地测试页面

---

## 🚀 Quick Start

### 1. 安装 Tampermonkey

首先在浏览器中安装 **Tampermonkey（油猴）**。

### 2. 安装秋招助手

打开：

```text
tampermonkey/campus_autofill.user.js
```

将脚本安装到 Tampermonkey。

### 3. 打开招聘网站

进入需要填写的校园招聘 / 网申页面。



启动成功后，页面会显示秋招助手操作面板。

### 5. 开始填写

点击：

```text
⚡ 一键填简历
```

即可根据本地简历资料自动匹配并填写页面字段。

## 🔒 Privacy

本项目默认使用本地简历数据。

GitHub 示例中的个人信息均为**虚拟测试数据**，请勿将真实的：

- 身份证号
- 手机号
- 家庭住址
- 家庭成员信息
- 紧急联系人
- 其他敏感个人信息

提交到公开仓库。

## ⚠️ Disclaimer

本项目仅用于**个人网申效率提升、自动化测试和学习研究**。

不同招聘网站的页面结构和字段实现可能存在差异，实际兼容情况以目标网站页面为准。

请遵守相关网站的使用规则，不要用于绕过验证码、反自动化验证或其他安全机制。
